Reproduire le dashboard course dans Looker Studio

Le même suivi de course qu'on a construit en HTML, mais via Google Sheets comme source de données et Looker Studio pour la visualisation et le partage. Suis les 7 étapes dans l'ordre.

01 La feuille de données 02 Connecter Looker Studio 03 Vérifier les types 04 Construire les visuels 05 Mettre en forme 06 Partager 07 Mettre à jour
1

Créer la feuille de données

C'est la base de tout : un tableau où chaque ligne est une course.

  1. Va sur sheets.google.com, connecté avec ton compte Google.

  2. Clique sur Vierge (le grand carré avec le +) pour créer une nouvelle feuille.

  3. En haut à gauche, clique sur Feuille de calcul sans titre et renomme-la Mes Courses.

  4. Sur la ligne 1, tape ces en-têtes, une par cellule de A1 à G1 :

    ABCDEFG
    DateVilleDistance_kmDuree_minAllure_min_kmDenivele_mFC_moyenne

  5. À partir de la ligne 2, ajoute une ligne par course déjà faite :

    2026-08-26Rennes10.75605.58115148
    Pour l'allure, écris une valeur décimale (5min35 → 5.58), pas 5:35 : Looker Studio ne sait pas faire de calculs sur un format texte "minutes:secondes".

  6. Sélectionne toute la colonne A → clic droit → Format des cellules → Date, pour que Sheets reconnaisse bien des dates et pas du texte.

2

Connecter Looker Studio à la feuille

Looker Studio ne stocke rien lui-même : il lit en direct ce qu'il y a dans le Sheet.

  1. Va sur lookerstudio.google.com.

  2. Clique sur Créer → Rapport en haut à gauche.

  3. Dans la fenêtre "Ajouter des données à votre rapport", clique sur le connecteur Google Sheets.

  4. Autorise l'accès si demandé, puis sélectionne le classeur Mes Courses → l'onglet Feuille 1 → coche Utiliser la première ligne comme en-têtes.

  5. Clique sur Ajouter en bas à droite, puis confirme avec Ajouter au rapport.

3

Vérifier les types de champs

Une étape qu'on saute souvent, et qui casse les graphiques ensuite si on l'oublie.

  1. En haut, ouvre Ressource → Gérer les champs ajoutés.

  2. Vérifie que Date a bien le type Date (icône calendrier).

  3. Vérifie que Distance_km, Duree_min, Allure_min_km, Denivele_m, FC_moyenne ont le type Nombre (icône #). Clique sur le type pour le corriger si besoin.

  4. Pour Ville, si tu veux une carte géographique plus tard : clique sur son type → catégorie Géo → Ville.

4

Construire les visuels

Quatre blocs suffisent pour retrouver l'essentiel du dashboard actuel.

  1. Indicateurs (totaux) — Insérer → Indicateur, dessine un rectangle. Dans le panneau de droite, choisis le champ Distance_km puis règle l'agrégation sur Somme. Répète pour Duree_min (Somme), et ajoute-en un troisième avec agrégation Nombre pour compter tes courses.

  2. Historique — Insérer → Tableau, dessine-le. Ajoute les dimensions Date, Ville, Distance_km, Duree_min, Allure_min_km. Dans le panneau "Tri", trie par Date décroissant.

  3. Progression — Insérer → Graphique en aires (ou à barres). Dimension = Date, Métrique = Distance_km.

  4. Carte (optionnel) — Insérer → Carte géographique. Dimension = Ville, Métrique = Distance_km.

    Ça affiche un point par ville où tu as couru, mais pas le tracé réel du parcours GPS comme sur le dashboard HTML actuel — Looker Studio ne sait pas dessiner un itinéraire.
5

Mettre en forme

  1. Sélectionne tout (Ctrl+A), puis ouvre le panneau Thème et mise en page à droite pour choisir une police et des couleurs cohérentes.

  2. Ajoute un titre : Insérer → Zone de texte, tape "Dashboard Course", place-le en haut.

6

Partager

C'est l'étape que le dashboard HTML actuel ne sait pas bien faire — ici c'est natif.

  1. Clique sur Partager en haut à droite.

  2. Ajoute l'email de ton ami avec le rôle Lecteur, ou ouvre Gérer l'accès → Modifier → Tous les utilisateurs disposant du lien pour un lien public en lecture seule.

  3. Copie le lien et envoie-le où tu veux.

7

Mettre à jour après chaque course

  1. Retourne sur ta feuille Mes Courses dans Google Sheets.

  2. Ajoute une nouvelle ligne avec les infos de la course.

  3. Reviens sur le rapport Looker Studio : il se met à jour automatiquement (sinon, clique sur l'icône Actualiser en haut).

Ce que tu gagnes vs le dashboard HTML : partage en un clic, mise en forme sans coder, accès depuis n'importe quel appareil connecté à ton compte Google.

Ce que tu perds : plus d'import automatique de fichier GPX/TCX (ici tu tapes les chiffres à la main après chaque course), et plus de carte avec le tracé réel du parcours — juste un point par ville.
